Update CHS when you are ready

  1. Edit the study source on GitHub and preview the draft.
  2. Choose the current draft or the frozen first release below, then copy its full study code.
  3. Open the grandmother study design in CHS. Replace its jsPsych Experiment Code with the copied code and save. Keep its plugin selections.
  4. Use the CHS preview to check consent, recording, the story choices, and the exit survey before using that version with participants.

GitHub edits update this preview after the site finishes publishing. CHS uses the code you last saved there; importing a new version is a separate step.
